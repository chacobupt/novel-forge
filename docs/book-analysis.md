# 500章以上长篇拆解：从整书到可迁移示范

拆书不是一次把全文塞进上下文，也不是只提炼开篇套路。历史流程对整书建立章节/行号索引，再按有界窗口逐段阅读，续传跨窗口线索，合成整书结构与方法。支持超过500章的作品。

## 已有记录

历史 FINAL_REPORT 记录：一部1498章作品75/75窗，一部1594章作品121/121窗，另一部正文末章题668的作品73/73窗（714个机械段，不把机械段等同章节）。合计269窗、约1428万文本字符。

266窗有数值分段日志且并集无缺口；2窗保留截断后补读说明；1窗只有完整阅读声明；另有一处分析由已有完整阅读笔记重建。以上是历史研究流程记录，不把覆盖统计等同每条语义结论独立验收。公开包不附原作全文或完整研究资产。

## 拆解结构

| 对象 | 记录什么 | 作用 |
|---|---|---|
| 来源与章节索引 | 原文件SHA、编码、章序、行范围、重复标题/机械段 | 可回查而不篡改原文 |
| 阅读窗口 | 覆盖范围、实际阅读回执、前窗未决线索 | 有界读取、断点续读、发现缺口 |
| 逐章因果 | 实际事件、原因与后果、进入下一章的变化 | 不只概括“发生了什么” |
| foreground | 实际展开的位置、方式、为何在此停留 | 学现场动作、心理、对话与视角 |
| passed_over | 概述/省略的位置与两端依据 | 学哪些手续与重复过程值得跳过 |
| information_timing | 人物与读者在何时知道什么 | 建立信息差、揭秘与期待变化 |
| 单元候选 | 连续故事、开放边界、渠道、详略经验 | 不用窗口边界伪造完整故事 |
| setup_payoff_links | 前置线索如何影响后续动作与回报 | 追踪铺垫、兑现和跨窗依赖 |
| 全书综合 | 阶段变化、长线、关系回流、节奏与结局接口 | 支撑卷级和全书设计 |
| 迁移示范 | 适配条件、可学习机制、不可照搬内容 | 进入few-shot检索与写作输入 |

原始研究schema与读取/验证逻辑见 `reference/distill.py`；其中作品列表已清空，目录与模型调用仍需适配，不能直接运行就假称完成研究。`tools/read_source_segment.py` 是可独立使用的原文分段读取工具。

先做整书结构研究，日常写作按当前缺口检索已有研究和少量完整窗口；不每写一章重新拆整本书。索引成功、读取成功、语义正确、文学可迁移是不同验收层。
