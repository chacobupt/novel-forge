# 八层参照方法

这些层是创作维度，不是质量等级；也不意味着每层都要填写一张表。

| 层 | 观察什么 | 新故事要实现什么 |
|---|---|---|
| L1 欲望 | 人物和读者各想得到什么 | 一个值得期待的具体结果 |
| L2 体验 | 等待、发现、认可、关系与享用 | 真实可感的情绪经历 |
| L3 机制 | 条件、行动、回应怎样改变预期 | 有因果的有效选择与回报 |
| L4 事件 | 变化怎样发生 | 原创事件及其后果 |
| L5 关系 | 谁的欲望改变谁的选择 | 配角的独立追求和实际作用 |
| L6 场面 | 信息何时可见，关键行动如何亲历 | 关键选择与兑现不被摘要跳过 |
| L7 实体特性 | 能力、身份、物件或机会为何诱人 | 可实际使用的原创优势 |
| L8 表达 | 详略、信息先后、心理与交流 | 自然阅读中成立的期待和回报 |

先用L1/L2/L3/L7立住构思，再由L4/L5/L6组织故事，L8用实际正文验证。不能以“有反转、有代价”代替因果，也不能以句子通顺证明吸引力。

每个参照对象至少说明：读到的范围、开始期待、改变期待的事件、所得与使用、留下的问题、可迁移条件与必须重新设计的具体内容。局部窗口不足以支持全书结构结论。

参照应服务当前缺口。先定位完整对象，再读足因果；不要为赶预算截断成伪完整故事。无需默认对整本书逐章填表。
