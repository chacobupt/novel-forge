# 已知边界与演进

公开版是方法包：没有网络模型客户端、自动调度器、发布程序或生产数据库。历史基线包含尚未修正的叠加指令；通用提示词是整理后的实验版本，二者不要叠加使用。

历史流程暴露的主要问题：固定容量与自然故事冲突；汉字和有效字符口径混用；两轮选稿同时改变顺序和参考材料；冷读混入逐句校对；轻微表达问题阻断全文；技术修账与内容复核混淆；来源目录与作品硬绑定；关键状态被展示条数上限截断。

通用合同改为明确阶段职责、自然容量、单独事实审查、分层修复和完整关键状态。但这些文字改进尚无完整长篇A/B验证，不能视为已证明更好。

模型适配应比较相同输入、相同预算和明确判据，记录真实路由，不把换模型名当迁移完成。独立上下文也不等于独立人类判断。

全局事实回写、并发锁、幂等恢复、用量账及发布授权，需要你的执行框架实际实现；提示词本身不能保证这些工程性质。
