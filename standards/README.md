## 当前补丁优先级

1. 最新任务边界优先；10月27日自然容量规则覆盖历史最低章数/字数硬门槛。预算、实际容量、阅读质量分别报告。
2. 冷读先只见实际正文与必要前情，区分写明/推断/未知；事实审核另读绑定材料。不得拿规划解释补正文缺口。
3. 当前`autonomous_prompts.py`中的章名、对白阅读价值、角色声音与形象、修后吸引力保留合同补充上述方法。展开合同已在`prompts/baseline/`公开。
4. 修后同时核事实与回报，不能通过删除决定性选择或把胜利改成免责声明消除问题。
5. 仅可选润色不成为必改；确证问题要说明损害。原始基线中minor表达也阻断的机制仍属已知争议，见limitations。
6. 按任务有界返修，记录失败与下一动作。ACCEPT/ADOPT表示当前范围建议，不代表作者批准或商业验证。

阅读顺序：单元用U规则→v5比较；正文用P/E/D→详略→A类→双判/跨场→必要参照→范围报告。规则服务判断，不要求小说逐项表演。
